# ccc-system-python
A mini CCC OS developed in Python

**lang zh 5 ~ 29**
**lang en 32 ~ 57**
## 功能

- 用户登录/注册
- 虚拟文件系统（ls, cd, mkdir, touch, cat, write, rm）
- 路径安全校验，防止越界访问

## 快速开始

```bash
python main.py
```
## 可用命令

| 命令 | 说明 |
|------|------|
| `ls` | 列出文件 |
| `cd <目录>` | 切换目录 |
| `mkdir <目录>` | 创建文件夹 |
| `touch <文件>` | 创建文件 |
| `cat <文件>` | 查看内容 |
| `write <文件> <内容>` | 写入文件 |
| `rm <文件/目录>` | 删除 |
| `add_user <用户名> <密码>` | 添加用户 |
| `rest` | 返回登录界面 |
| `exit` | 退出程序 |

## Features

- User login/registration
- Virtual file system (ls, cd, mkdir, touch, cat, write, rm)
- Path validation to prevent out-of-bounds access

## Quick Start

```bash
python main.py
```

## Available Commands

| Command | Description |
|---------|-------------|
| `ls` | List files |
| `cd <dir>` | Change directory |
| `mkdir <dir>` | Create a directory |
| `touch <file>` | Create a file |
| `cat <file>` | Display file contents |
| `write <file> <content>` | Write content to a file |
| `rm <file/dir>` | Delete a file or directory |
| `add_user <username> <password>` | Add a new user |
| `rest` | Return to the login screen |
| `exit` | Exit the program |
